# Customer Shopping Behavior Analysis (SQL + Python + Power BI)

This project explores customer shopping behavior using **SQL**, **Python**, and **Power BI**.  
It extracts patterns from real purchase data to understand **who the customers are**, **what they are buying**, and **how their buying preferences change across segments**.

The purpose is to turn raw customer transactions into meaningful **business insights** that can support decision-making, customer retention, and product strategy.

---

## 🎯 Objectives

- Clean and analyze customer purchase data
- Identify revenue drivers across segments
- Compare customer behavior (gender, age group, subscription status)
- Evaluate discount effectiveness and product ratings
- Build customer segmentation groups
- Create a Power BI dashboard to visualize insights
